# Contracts

`openapi.json` is the versioned `/api/v1` contract generated from FastAPI
(`make contracts`). The web app generates TypeScript types from it
(`npm run gen:types` → `apps/web/src/lib/api-types.ts`). CI regenerates it and fails if
it changed without being committed, so the API and UI can never silently drift.

MCP tool schemas are generated by the MCP SDK from the typed tool signatures in
`services/api/app/mcp/server.py`.
